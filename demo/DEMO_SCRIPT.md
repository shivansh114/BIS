# 2-minute demo — one hard case, done well

Before judges arrive: `ollama list` shows bis-assistant · `START_DEMO.bat` running · browser on http://127.0.0.1:5000 · Wi-Fi OFF (proves it's local)

0:00  "BIS has 23,813 standards. If you don't know the technical name, finding yours is hard. Watch."
0:10  Open the chat. Type:  **I make cable for house wiring**
0:20  It asks which cable — point at the options. "It doesn't guess. When several standards fit, it asks."
0:30  Click **PVC Insulated Cables (up to 1100V)** → IS 694, mandatory, Electrical Wires & Cables QCO.
      "Every fact here comes from a BIS record — the model only words it."
0:50  Click **Steps**, then **Documents**. "This is where people pay consultants today."
1:05  Click **Fill form** → green auto-filled fields → type a company name → Download PDF.
1:20  Type in Hinglish:  **helmet ka standard kya hai**  → answers in Hinglish.
1:30  Type:  **how to cook biryani**  → politely declines. "It refuses what it doesn't know."
1:40  Point at the Wi-Fi icon: "Internet is off. Our fine-tuned Llama runs on this laptop — no cloud API."
1:50  "For licence checks we hand off to BIS Care. We make BIS services easier to reach, we don't replace them."
